# MechWarrior 3 Recomp

**Original gameplay. A modern core.**

An experimental native recompilation of MechWarrior 3, preserving the original game's logic and behavior while integrating modern Windows services and Vulkan rendering.

## Development status

The project is actively in development. Compatibility, fidelity, performance and broader playtesting remain ongoing work.

This repository is the public home for project information and community feedback. The source code remains private while we prepare an open-source release. No source release date has been announced. When ready, reviewed source code will be published here.

Star or watch this repository to follow the project. Use [Issues](https://github.com/roswellien/MW3Recomp/issues) for questions and feedback. Please do not upload original game files, proprietary assets, memory dumps or private playtest packages.
