# Documentation index

This is a documentation-only snapshot of the private development project as of October 25, 2026. Source code and build inputs are not published here. Dated documents retain their historical scope and limitations; they are not claims that a release or feature is complete.

Start with the [project overview](../README.md), [screenshots and videos](media/README.md), [roadmap](roadmap.md), [game setup and limits](setup-game.md), and [distribution policy](legal.md).

Private review/playtest URLs, implementation and instruction excerpts, and links to unpublished source or local artifacts have been omitted from these public copies. CLI examples document development workflows and need the corresponding private inputs. The original private documents and evidence are unchanged.

Internal agent instructions, an operational continuation handoff, and the detailed unreleased security review are not part of this snapshot. Only the five reviewed gallery JPEGs are copied; launcher artwork with unresolved provenance, downloadable game/media assets, generated code, raw reports, configuration files and source history are excluded.
