# Announcement trailer edit

This records the superseded first edit. The current
[second revision](announcement-trailer-revision-2-2026-10-19.md) removes Vulture
and includes a fresh native capture of the updated Mad Cat after the user
released its hold.

The first private review edit is a 2:30 announcement trailer combining the
existing Core Critical intro, native game video and screenshots, short feature
titles, original MW3 music and original game sound effects. It introduces the
announcement at ten seconds and closes with an in-development title card.

## Scope

The 32-shot edit includes 13 current mech models, campaign coastal and dockside
views, and four Instant Action environments under different captured sun presets.
Mad Cat gameplay remains held pending the user's explicit release. The existing
branded intro retains its illustrated artwork and original game-audio mix.

Visual review excluded Daishi's flat-looking captured materials and replaced
Orion/Sunder walking views crossing a fountain with clearer stills. Source
captures remain preserved; this edit does not fix those underlying capture issues.

The music bed uses the user's supplied MW3 Track 01, original CD track 2.
The source captures are silent, so original bank sounds are placed editorially
for the body. Audio provenance and cue timings are saved locally; no standalone
game soundtrack or sound-effect files are added to the review delivery.
