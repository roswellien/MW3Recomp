# MW4 donors for the four missing MW5 chassis

The installed MW5 archive inventory found no main meshes for Avatar, Firefly,
Owens or Strider. The user asked whether any MW4 release or expansion/mod has
newer models. This is a roster/documentation check, not an extracted-asset result.

| MW3 chassis | MW4 evidence | Donor status |
| --- | --- | --- |
| Owens | Original Microsoft MW4: Mercenaries manual, specifications table, PDF page 13 | Confirmed in the official game roster |
| Avatar | Warhead's MW4 technical reference describes the playable MekTek Avatar and changes in Mech Pack 2.1 | Confirmed MekTek donor candidate |
| Strider | Same technical reference documents the playable Strider and changes in Mech Pack 2 | Confirmed MekTek donor candidate |
| Firefly | No released model confirmed from the sources checked | Still unresolved; do not count a planned model or erroneous roster listing as an available donor |

Primary documentation used:

- [Microsoft MW4: Mercenaries manual, mirrored on Sarna](https://cf.sarna.net/docs/products/manuals/mechwarrior_4_mercs.pdf).
- [Warhead's direct MW4 Avatar reference and gameplay measurements](https://draketungsten.org/arcade/pcmanuals/mech4fieldguide/avatar.htm).
- [Warhead's direct MW4 Strider reference and gameplay measurements](https://draketungsten.org/arcade/pcmanuals/mech4fieldguide/strider.htm).

MW4/MekTek model presence makes these possible donors. Actual mesh detail,
segmentation, textures, rig recovery and improvement over MW3 remain unverified
until a user-provided installation can be inspected. No MW4 game content was
