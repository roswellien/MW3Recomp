# Connected startup initializer component

The component admits two adjacent exact CRT roots, the accepted complete route at `0x410910` and the complete route at `0x410940`, including its tail body at `0x410950` and complete callees at `0x40DAF0` and `0x40DB30`. It covers the concrete initializer caller's fixed register/stack arguments. Unrestricted standalone helper arguments and aliased output/stack spans are outside this contract.

All four original bodies are statically lifted and linked. The actual generated direct calls execute complete compiled helper definitions; the return hook checks their actual `RET12` and `RET20` destinations and stack cleanup. Instrumentation captures incoming and returned helper CPU values without changing guest computations. Memory bridges check addresses, widths and access order, retain actual emitted values, and never execute an expected-value implementation.

The candidate requires a mapped readable/writable stack span `[entry ESP - 28, entry ESP + 4)` disjoint from executable bytes and globals. The exact shared page at `0x604000` is writable PE zero-fill. The new route writes 66 bytes at `0x6040D0..0x604112`, through 32 global dword writes and five global byte writes, and leaves all other page bytes unchanged. Its 60 architectural memory accesses include stack pushes, calls, argument reads, returns and the saved EBX pop. The earlier 167 byte clears occupy a disjoint part of this same page.

Final candidate EAX is `0x604100`, ECX is `0x6040D0`, EDX is zero, ESP advances four bytes, and EBX/EBP/ESI/EDI persist. All six arithmetic flags are defined by the final ADD in the indexed helper: CF=0, PF=1, AF=0, ZF=0, SF=0, OF=0. DF persists. Intermediate XOR AF and shift AF/OF are undefined; a complete CFG and SSA/State use proof must show they are overwritten before any load or State boundary before the adapter can lower the upstream undefined helper. No exit flag is excluded.

Offline mode zero executes the candidate on authored seeded pages. Mode one executes the accepted clear then the candidate on the same persistent pages and Remill State, preserving each intermediate snapshot. Between calls the harness rearms only the top-level PC and stack frame to model the next CRT call; it does not reset other GPR, FP, State or data bytes. Original Remill State and per-access/callee observations are explicitly unobserved zero; native observations are actual snapshots and bridge/hook records.

Guest FP admission retains the reviewed twelve masked x87 control words, TOP/FTW/raw80/XMM storage domain, zero-only FOP/FIP/FDP, coherent tags and fixed MXCSR. Whole guest pages, defined CPU/flags, protected State and actual FP/ENV must agree. Native host FP storage and environment must restore on normal and checked fault paths. Arbitrary trap/EH domains are excluded.

The executor borrows checked GuestMemory rather than seeding it. Authored offline page initialization is a separate harness. The production registry adapter must use the shared admitted image and persistent 3504-byte State, overlay only known CPU/FX fields, preserve address-space/FS state, and return actual CPU EIP/ESP for dispatcher validation. This component is a startup prerequisite and does not establish full native CRT, MFC application initialization, menus or gameplay.

The new registry adapter registers both complete concrete roots in the frozen shared M4 runtime. An owned-image control snapshots the complete recovered 145-slot table and invokes the exact adjacent targets at slots 22 and 23 through that dispatcher at O0 and O2. It does not run or complete the full table ledger. A separate actual two-call control seeds nonzero legacy metadata in persistent State between the compiled callbacks and proves it survives along with FS. The adapter preserves State x87 bytes 6..23 across subsequent integer callbacks and retains the distinct incoming Runtime FX bytes 6..23 on output. This does not grant equivalence credit for original FP instructions or establish metadata conversion for a future FP adapter.

Evidence publication assumes normal Windows, fresh ordinary private directories, sequential workers, and no concurrent writers or reparse points. The new scaffold inherits the reviewed staging-before-cleanup and entirely fresh report/all-three-build-directory admission safeguards. Atomic production publication remains outside this offline equivalence contract.
