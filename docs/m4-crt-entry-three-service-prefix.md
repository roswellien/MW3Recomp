# Native CRT entry: first three connected services

The translated ordinary entry now executes at O0/O2, installs its guest FS
exception frame and returns through the measured `__set_app_type`,
`__p__fmode` and `__p__commode` service implementations. It then reports an
explicit missing initialized-data dependency at the `_adjust_fdiv` import.
This is a bounded startup integration result; full CRT and M4 remain open.

The root source/input observer independently predicts all 26 reached game
instructions, complete 3,504-byte persistent State, four memory pages, three
provider DWORDs, implemented NT_TIB fields, 26 game memory events and four
call records per build. The root call stays incomplete at the denial; the
three import calls complete. Fifty-six altered State, memory, event and route
controls are rejected. Provider effects also follow freshly decoded original
MOV/RET bodies; those provider instructions are not captured Remill game
events. No State is reseeded between the three services.

The game IAT cell contains its original import lookup RVA. That value is
distinct from the provider's file-initialized `_adjust_fdiv` DWORD, which is
zero. The probe validates exact import ownership and reports the missing data
connection before completing the source MOV. It neither guesses an initialized
value nor substitutes a host pointer. Retrying the poisoned context preserves
its State and event record.

The earlier first-fault probe remains a separate baseline: it installs the
same exception frame, executes sixteen game instructions and stops at the
unconnected first service. Failed builds/checker drafts and the incorrect
zero-IAT assertion remain preserved before their additive repairs. The complete
entry objects still cover eleven roots and 148 static source instructions;
this preparation is distinct from the 26 instructions executed here.

The initial integer State/stack policy is authored research input. Its unchanged
software FP image does not prove numerical coherence or caller-host preservation.
Only implemented NT_TIB fields are mapped, and guest exception dispatch is not
implemented. Remaining CRT services, initializer coverage, application callbacks,
rendering, input/audio and native menus remain required. Compiled causal review
of the composition and original game entry comparison are separate gates.

The private evidence is `reports/m4-crt-entry/prefix-build-r3` and
`prefix-observation-r2`. Reproduction uses the additive `build-prefix-v3.ps1`
recipe and `observe_prefix.py` with a fresh report directory. These workers
execute native translated code; they do not launch the original game.
