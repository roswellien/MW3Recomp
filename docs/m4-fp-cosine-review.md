# Four cosine initializer review

The independent raw review (not included in this public documentation snapshot)
and author archive association (not included in this public documentation snapshot)
pass with no findings in the bounded standalone domain. They verify 6,144
actual original / 12,288 native directed records, 192 / 384 default records,
3,072 original guest repeat pairs and 136 independent corruption controls.
The association rehashes all 1,021 author bindings and preserved histories.

The [authored experiment](m4-fp-cosine-experiment.md) remains the frozen
pre-review checkpoint. The review additionally confirms the exact allowed
status repair, actual compiled guest/bridge objects, every native State byte,
whole pages, CPU, separate FX/legacy ENV observations and actual native events.
Original State and event traces remain unobserved.

Only 384 original records have independently proved final-store C1 meaning:
their finite out-of-range FCOS input remains unchanged, then narrows inexactly
to binary32. The other 5,760 matching C1 values, final C0/C2/C3 and empty-tag
raw80 payloads retain observation credit only. The measured domain has masked
exceptions, empty x87 tags and TOP 0/7 on the observed machine.

This accepts the four standalone comparisons. Shared Runtime FP integration,
connected initializer order, broader incoming state and native startup/menu
execution remain open M4 requirements.
