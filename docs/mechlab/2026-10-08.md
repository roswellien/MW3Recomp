# Native helper bridges, Vulkan direction, and textures in Training

Development tested compiled native helpers inside the original game's execution path and selected Vulkan as the graphics direction. Local play also confirmed that the first texture integration was reaching the intended Training assets.

## Native components in the original game

A verified address helper and a numeric startup initializer ran through separate native x64 workers. The original x86 game consumed their checked results, and user tests reached Training and quit through the experimental launchers.

This was original-game execution with isolated native replacements. It was useful integration evidence, but it was not a fully recompiled game or completion of native startup.

## Graphics and assets

- Selected Vulkan for the modern graphics backend and began the associated learning and integration work.
- Corrected texture-bank coverage so the Bushwacker's alternate 16-bit bank received the intended replacements.
- User review confirmed the Bushwacker and Training terrain upgrades appeared in-game; other asset families still needed individual checks.
- Continued local cinematic upscaling and frame-rate experiments, including a full opening-movie experiment.

The opening-movie experiments described here were later withdrawn and replaced by a different approach. They are part of the development history, not current downloadable deliverables.

## What came next

The project still needed live graphics observation, faithful rendering comparisons, and a native host that could execute the application itself.
