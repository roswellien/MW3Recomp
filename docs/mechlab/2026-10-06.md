# Building the recompilation foundation

Development began with a reproducible research and build foundation for MW3. The first goal was to prove that small pieces of original-style x86 behavior could be translated, compiled for modern Windows, and checked against an independent reference.

## What changed

- Identified the MW3 U.S. retail 1.2 target and recorded the supplied installation and media identities.
- Established the project architecture, research workflow, native host experiments, and a conservative distribution policy.
- Built an authored arithmetic fixture and compared original x86 execution with compiled native x64 output at two optimization levels.

## What the first proof established

All 10,144 cases in that arithmetic experiment matched. The checks covered registers, arithmetic flags, stack behavior, and mapped memory, with deliberate corruption controls to confirm that mismatches were detected.

This was an authored test fixture, not a translated MW3 function or a running native game. It established a way to measure correctness before attempting larger game components.

## What came next

The next step was to expand the instruction and memory tests, select a small real game function, and make every accepted result reproducible. Original executables, media, and generated game translations stayed local.
