# Seeing the original renderer and expanding startup coverage

The graphics work gained a live trace of the original game and a standalone Vulkan viewer for captured scenes. In parallel, reviewed startup coverage continued to grow and the first GitHub repository snapshot brought the project-authored tooling together.

## Graphics research

Original-game tracing captured a Training scene's draw commands, textures, and rendering state. A separate windowed Vulkan viewer replayed that saved material, including resize, minimize, restore, and normal close behavior. Authored rendering fixtures checked texture, depth, fog, and blending behavior.

The viewer replayed recorded scenes; it did not execute native gameplay. Original-game tracing and native game execution remained distinct evidence paths.

## Startup and tooling

The dated startup records reached 125 accepted roots out of a selected inventory of 144. This was a specific startup checklist, not a percentage of the whole game. Source recovery, resource ownership, failure controls, and original/native comparisons remained part of each closure.

The repository also gained Windows and Linux bootstrap CI, while widescreen and HUD investigations documented original behavior for later graphics work.

## Future-game reconnaissance

MW4 Mercenaries received an initial installation and compatibility assessment. The recorded launch attempts did not reach its menu; legacy disc-protection and modern-Windows compatibility obstacles remained. This was reconnaissance, not an MW4 recompilation milestone.

## What came next

The next work connected more startup components and investigated the rendering commands and HUD details still missing from the replay path.
