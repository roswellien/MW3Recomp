# CRT command-line reference ownership independent review

The independent review (not included in this public documentation snapshot)
accepts the bounded original writer observation and typed reference projection
ownership gate. It checks all 192 original records with an independently
written input-derived CPU, complete stack/global, FX and legacy-environment
model. The exact staged writer, game data-import owners and actual x86 Windows
API export/provider identities are checked directly from the files.

Its 56 corruption controls reject and one legitimate readable-allocation
extent-growth control passes. A separately authored compiled harness links the
unchanged frozen O0/O2 ownership libraries and passes 567 checks over 41
scenarios at each level. These cover arena endpoints, maximum buffer extent,
complete CPU/FX/3,504-byte State preservation, malformed admissions, retained
first faults, reuse denial, collisions and partial cleanup. Six actual objects
are freshly decoded. All 738 author bindings and seven explicit historical
source associations are resolved physically; the independent
pins (not included in this public documentation snapshot) contain 782 bindings.
The initial reviewer extent-control mistake and both literal checker versions
are preserved with their declared association.

The observed command line belongs to the original probe process. The registry
copies explicitly declared reference bytes into owned guest storage and stores
their projected pointer through an authored fixture. Its records remain
`reference_projection_only=true` and `production_initialized_service=false`.
This gate implements no native GetCommandLineA service or translated writer,
and establishes no production initialized `_acmdln` or `_adjust_fdiv`.

Runtime must outlive the registry. Concurrent callers and host replacement of
owned mappings are excluded. Read-only buffer permissions are established at
admission; deliberate permission changes without byte changes are outside its
integrity check. The actual native writer, own command-line input, data-import
routing, complete process attach and full M4 remain open.
