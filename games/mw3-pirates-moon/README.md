# Pirate's Moon experimental native target

The supplied U.S. candidate is pinned independently in `config/`. This admits
an exact research input, not native compatibility or MW3 M4 acceptance.
Its installation provenance remains incomplete.

Use the existing runtime and translation pipeline through
[the PM tools](../../tools/pirates-moon/README.md). Required original binaries,
assets, generated LLVM, native objects and analysis evidence remain local.
MW3 is still the default target and retains its existing acceptance criteria.

The current Windows x64/Vulkan build executes menu -> Options -> menu -> quit
with normal native dependency detach. All 210 scene fingerprints match the
original-side reference. See the [local handoff and limits](../../docs/pirates-moon-native-startup.md).
Missions, cinematics and manual physical-input testing remain open.
