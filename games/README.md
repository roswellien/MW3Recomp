# Game targets

`mw3/` remains the default implementation target. `mw3-pirates-moon/` is an
experimental separate native target using verified local inputs and the shared
translation/runtime infrastructure; see its README for execution limits.
MW4 Vengeance, Black Knight, and Mercenaries remain future targets. Shared code
should earn generalization through evidence.

The installed MW4 Mercenaries now has a [static assessment](../docs/mw4-reconnaissance.md)
and a [proposed recompilation execution plan](../docs/mw4-execution-plan.md).
Its protected game-code image must be resolved before native implementation.
