# Independent ordinary heap-mode observer

The observer derives ordinary expectations from the frozen original BEFORE inputs, original provider instructions and the explicitly declared lower-stack input. Native AFTER captures supply comparison targets and typed host API identity/ownership witnesses, never the expected machine-state seed.

`before.py`, `prefix.py` and `draft.py` were frozen before the independent draft model audit. `positive.py` compares complete State, FX, runtime CPU, 20 mapped pages and original source identities at 34 checkpoints. It also checks the source ledgers, probe RET, unresolved query CALL, private heap lifecycle, unused service records and poisoned retry.

Native executors are the delegated author and independent reviewer. Root performs source modelling, archive and stage verification, receipt binding and final acceptance. It takes no independent native-execution credit.

The lower page is a declared owned research input; TIB and Policy limits are preserved. Probe RET is complete. `GetVersionExA`, selector RET, heap-initializer RET, locale, parser and full M4 are incomplete. The selected initializer count remains 27/144.
