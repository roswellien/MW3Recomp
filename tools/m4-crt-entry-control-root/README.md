# Root verification of the actual CRT control composition

The accepted bounded composition runs the literal compiled FDIV writer, game
CRT entry, math-error registration and complete game `_controlfp` route on one
persistent State/Runtime. It stops at source CALL `0x5AC440` to the `_initterm`
thunk `0x5AC598`, before the first null-only initializer interval executes.
It does not start the ordinary game or create a native menu.

`run.py` executes both final O0/O2 workers after verifying build/source/tool and
input identities. `model.py` extends frozen independently authored instruction
models and predicts the connected path from original BEFORE inputs and the
actual OS query result. `observe.py` checks complete and stopped checkpoints,
events, typed transfer, caller state, call records and poisoned retries.
`accept.py` binds the completed proof, separate independent source/object,
compiled-fault, hardware-observer and read-only model reviews, plus prior
accepted component gates.

The frozen final build is `reports/m4-crt-entry-control/build-r6`, derived from
`preparation-r5`. A new local build can be created with `build.ps1`, which binds
that preparation. Use fresh output names; all tools refuse existing output
directories. From the repository root, these commands reproduce root execution
and source comparison in new private directories:

```powershell
& 'C:/Python314/python.exe' tools/m4-crt-entry-control-root/run.py reports/m4-crt-entry-control/build-r6 reports/m4-crt-entry-control/root-execution-recheck
& 'C:/Python314/python.exe' tools/m4-crt-entry-control-root/observe.py reports/m4-crt-entry-control/build-r6 reports/m4-crt-entry-control/root-execution-recheck reports/m4-crt-entry-control/root-model-recheck
```

These commands require the local admitted game/provider images and preserved
original BEFORE evidence. Raw inputs, derived IR/COFF and full observations
remain private local evidence. The root seal deliberately names the independently
reviewed final receipts; fresh rechecks need their own audit and acceptance
association before receiving new acceptance credit.

The original entry/math-error objects and FDIV library remain frozen. The
control object is a newly compiled derivative with exactly nine reversible
symbol names; earlier control objects remain preserved. Runtime r9 and the
encompassing FX/legacy ENV invocation guard remain unchanged.

The final observer covers 48 positive compositions and 72 causal prefixes,
all State3504/FX512, fourteen pages and 900 source identity bytes. Guest scope
remains twelve masked control words, empty TOP0 stack and two repetitions.
Failed provider POP-read partial ordering remains outside this corpus. The
earlier failed source-observer revisions are preserved alongside final proof.
The selected initializer count remains 27 of 144; full CRT/table/menu execution
and M4 completion remain open.
