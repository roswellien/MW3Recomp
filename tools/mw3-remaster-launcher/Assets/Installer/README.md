# Installer artwork

Native Inno Setup 7 wizard artwork, following the existing launcher identity:

- `wizard-welcome.png`: 492 x 942 RGB, charcoal canvas, Core Critical mark and
  wordmark, MechWarrior 3 label, and a crop of `../Plates/hero-art.png`.
- `wizard-mark.png`: 192 x 192 RGB, mark from `../Plates/brand-mark.png` on
  the launcher's charcoal background.

Typography uses the launcher's Orbitron and Barlow fonts. Palette: ground
`#141717`, deep background `#0F1212`, amber `#EFA348`, ink `#EEE6DC`, muted
`#C4C4BE`, rule `#373B3A`. No external skin library is needed.

These files are embedded by `installer.iss` and excluded from installed assets.
