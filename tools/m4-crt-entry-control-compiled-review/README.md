This is an independently authored compiled fixture for the bounded FDIV → CRT
entry → math-error registration → real game control wrapper/provider composition.
It compiles the production composition with only its CLI main excluded and links
the exact entry/matherr objects, reversible-symbol-mapped control objects and
registry library. It does not launch MW3.

The fixtures exercise real translated access/frame failures, strict current-owner
token dispatch and terminal first-diagnostic retry. The caller fixtures measure
actual hardware before and after both the producer and the root call including
the outer C++ fault catch. They cover complete legacy ENV metadata, empty and
occupied physical x87 tags, raw 80-bit registers, sticky status, masked CW,
MXCSR and the Windows x64 nonvolatile XMM registers.

`review.py` rehashes the compiled build and actual captures, checks the direct
hardware corpus independently, and inspects actual COFF disassembly and unwind
data. Guest source execution is separately modeled by the parent; this reviewer
does not infer a guest result from captured AFTER State or grant broader original
process equivalence.
