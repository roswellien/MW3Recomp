# Independent locale root-model audit

This audit reads original source and previously accepted FDIV input/API
witnesses. It executes Python source models and the LLVM disassembler only.
It runs no original provider, native worker or game.

The seam expectation comes from the pre-provider snapshot of the complete
frozen mainargs source interpreter. The root's stopping subclass does not
supply that expectation. The audit checks all 48 ordinary BEFORE-derived
rows, then derives the complete locale prefix independently from the static
original-source affine access ledger: 20 PCs, 15 ordered accesses, three real
nested CALL frames and one separately declared scheduling store.

It compares whole 3,504-byte State, 512-byte FX, 40-byte RuntimeCPU and all
17 pages, including the additional literal `78003000` RX source page. It checks
flat SS addressing, unchanged generic RuntimeCPU, source arithmetic flags and
the retained malloc frame. It claims no full independent model of fault rows.

Run with a fresh private output name:

```powershell
& C:/Python314/python.exe tools/m4-crt-locale-default-root-audit/audit.py reports/m4-crt-locale-default-root-audit/draft-r1
```

For the final audit, provide all three frozen root receipts with `--execution`,
`--observer` and `--stage`. The draft audit grants no current native proof. The
final run binds the successful execution/model/stage and their current pins;
it does not derive expectations from native AFTER machine bytes.
