# Independent native filename composition

The root gate consumes final `preparation-r8/build-r7`, retaining all twelve
accepted guest objects, two FDIV libraries and eleven ancestor components.
It executes isolated AMD64 workers; it does not launch MW3 or original x86 CRT.

- `run.py` creates fresh native stages and capture bundles. The retained
  `root-execution-r1` passed O0 execution but timed out during legacy conversion.
- `resume.py` binds that exact failed receipt and successful O0 stage, executes
  fresh O2, and publishes both strict bundles under `root-execution-r2`.
  O0 adoption is explicit; no new O0 run is claimed by the recovery.
- `observe.py` explicitly reads bundle entries. It imports only SHA-pinned
  independent frozen root source models. Every guest expectation originates
  in original pre-execution captures and literal code, followed by a declared
  native OS-service ABI. Candidate expected-value helpers are not imported.
- `accept.py` merges the final current manifests once with normalized path
  conflict checks and rehashes every unique physical dependency. Superseded
  source manifests are historical receipts rather than current closure inputs.

Final root observer `root-observer-r3` checks all 72 complete guest sequences,
eight actual API capacity units and 146 ordinary hardware boundary pairs.
It checks State3504, FX512, sixteen pages, 1,140 source bytes, complete ordered
ledgers, partial effect ordering and terminal cleanup. There are 952 shared
validator rejection checks across 680 distinct selected byte locations;
repeated before/API checkpoints account for the difference. Earlier observer
failures retain incorrect outer-catch attribution and a nonexistent writer-job
read. The corrected expectations follow the frozen source and actual driver
schema; the candidate and captures did not change.

The filename API reports the actual native worker executable. Its full 260-byte
buffer scratch starts from the owned guest bytes. The checked complete guest
copy precedes EAX/ESP+16/PC publication. Actual API/worker identities and
physical hashes are independently checked, including separate unit records.
The original x86 API's volatile register/flag effects and guest TEB LastError
are not claimed. The continued compiled MOV at BBD6 is refused before loading
the uninitialized `_acmdln` pointer at 78037174.

next required producer. Main-table initialization and native menus remain open.
