# Independent CRT caller and math-error registration observer

`run.py` executes fresh, hash-bound O0/O2 native workers. `model.py` extends
the frozen root FDIV/entry source observers with the four actual provider
instructions and game continuation. `observe.py` compares the complete native
checkpoints, events, call ledger, partial failures and terminal retries.

Inputs are the 24 preserved original FDIV BEFORE records, exact game/provider
PE source pages and the actual OS feature-query observation. Native AFTER
records are comparison evidence only. No candidate fixture model is imported.

The positive path registers guest callback `0x51E7B0`, executes the game stack
cleanup and stops at required direct call `0x5AC431` -> `0x5AC5A0`. This is a
bounded research worker. Full CRT initialization, callback execution, guest
exception dispatch, the full initializer ledger and native menus remain open.

Usage from the project root, with fresh output directory names:

```powershell
& 'C:/Python314/python.exe' tools/m4-crt-entry-matherr-root/run.py reports/m4-crt-entry-matherr/build-rN reports/m4-crt-entry-matherr/root-execution-rN
& 'C:/Python314/python.exe' tools/m4-crt-entry-matherr-root/observe.py reports/m4-crt-entry-matherr/build-rN reports/m4-crt-entry-matherr/root-execution-rN reports/m4-crt-entry-matherr/root-model-rN
```

Failed iterations and superseded receipts are retained. A passing source model
does not supply broader host-boundary coverage: acceptance also requires the
separate compiled review with deliberately populated legacy x87 metadata.
