The changed unit registers 26 exact callback code addresses on a persistent live
heap and a genuinely initialized lazy lock 13. It receives initializer credit
only after the whole connected source/native unit passes. Registered callbacks
remain data; this review never passes them to Windows as native function pointers.

Expected source effects come from the original DLL bytes and an independent x86
interpreter. Inputs are complete BEFORE State/FX/pages and finite actual API
witnesses. A captured AFTER machine never seeds expectations. Native HeapSize
capacity differs from requested/rounded allocation size and controls growth.

The independent compiled fixture will preserve the frozen candidate/owner bytes
and objects. Its only changes are rich host hardware seeds, observers and causal
input/permission mutations. All records are written directly into canonical
strict archives; authored denial and actual API failure evidence stay separate.

Required controls include:

- Foreign-thread finish and lookup before any native release or API invocation.
- Wrong, stale and interior allocation aliases, source/IAT identity mutation and
  callback argument/RET frame forgery at the exact live source boundary.
- Read-only append target before source store, retaining constructor writes and
  earlier registered callbacks.
- Pre-realloc mapping/permission collision denial before native API invocation.
- Post-realloc observer exception and partial guest output transfer fault,
  retaining the new actual native pointer as private cleanup ownership.
- Observer exception after genuine registration RET and consumed/poisoned retry
  denial without further source or API work.
- Actual HeapSize witness, directed genuine source replay across measured
  capacity, full byte preservation and source begin/next relocation.
- Cleanup releases held lock, deletes each native critical section, frees live
  allocation backing and finally destroys its heap exactly once.

Each compiled invocation is bracketed outside its large native frame by full
FX512 plus legacy ENV28 capture. Comparison covers loaded CW/SW/FTW/MXCSR, every
physical raw80 x87 value, native nonvolatile XMM6..15, caller LastError and DF.
