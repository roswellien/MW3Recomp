# HeapCreate ownership and original-BEFORE admission

`consumer.py` pins the immutable prior consumer. `before.py` derives the healthy
mainargs seam from original BEFORE inputs, with the new raw RW page alongside
all prior mappings. `prefix.py` independently models the original caller,
initializer, finite API return contract and source-only heap token publication
through the mode-selector CALL. Its API-return read is separate from the ten
original-source accesses.

`draft.py` exercises the source model without executing a native worker or API.
`observe.py`, `positive.py` and `ownership.py` compare current ordinary captures,
complete guest machine snapshots, exact source/later-service ledgers and the
typed actual host API/ownership witness. Host metadata follows a separately
derived initial/live/closed lifecycle. It is not candidate guest machine state
used as an expected-value seed.

Generated AF zero is scoped independently to source XOR `780039BF` and TEST
`780039D6`. The guest API ABI model preserves all other carried guest bytes;
unexecuted original x86 API internals and universal volatile/AF behavior are not
claimed. Compiled fault fixtures give no full causal-model credit.

`create_config.py` binds fixed production, source, independent native/hardware,
nonzero caller-error and affine-audit receipts. `accept.py` checks their typed
contracts, actual completed native/archive stages, six complete strict bundles
and a deduplicated full-hash physical closure. `final_check.py` verifies the
finished admission stage, fixed closure, syntax and local document links. No
worker is launched by these root tools. Inherited observer names containing
`new_compiled_source_bytes` describe the reused 84-byte guarded footprint;
admission reports zero new guest objects and zero new guest compiled bytes.

The root acceptance (not included in this public documentation snapshot)
records 72 production scenarios, 132 independent hostile cases and 12 separate
nonzero host-error cases. The final independent affine audit (not included in this public documentation snapshot)
binds all 48 ordinary native rows and their 31 complete checkpoints.
